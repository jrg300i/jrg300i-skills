Skills de agente AI: reglas Laravel del proyecto y reparación de la shell de opencode en Termux.

## Skills

| Skill | Descripción |
|-------|-------------|
| [jrg300i-laravel-reglas](./skills/jrg300i-laravel-reglas/SKILL.md) | Reglas Laravel: MVC, migraciones I-P-R-A-T, Services, seguridad, Docker (22 secciones) |
| [repair-opencode-shell](./skills/repair-opencode-shell/SKILL.md) | Repara la shell rota de opencode en Termux (LD_PRELOAD del wrapper opencode-termux, sin arranque tras parchear) |

## Instalación

```bash
npx skills add jrg300i/jrg300i-skills

# Solo un skill
npx skills add jrg300i/jrg300i-skills --skill jrg300i-laravel-reglas
npx skills add jrg300i/jrg300i-skills --skill repair-opencode-shell
```
